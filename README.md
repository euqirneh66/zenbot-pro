# ZenBot Pro ⚡

> **Next.js 15 & TypeScript Algorithmic Crypto Trading, Backtesting Engine & Strategy Dashboard.**

ZenBot Pro is a modern, modular, and production-ready algorithmic cryptocurrency trading platform. Revitalized and re-engineered with the latest modern web stack (Next.js 15 App Router, React 19, TypeScript, and Tailwind CSS), it provides a complete turnkey interface for backtesting automated strategies, analyzing candlestick market data, and simulating automated order execution.

## 🚀 Key Features

- **Interactive Candlestick & Volume Charts**: Real-time rendering with EMA 20/50, RSI indicators, and strategy buy/sell signal overlays.
- **Visual Backtesting Engine**:
  - Test strategies against historical market data (RSI Mean Reversion, Trend Following, Grid Trading, Bollinger Scalper).
  - Comprehensive performance metrics: Win Rate, Profit Factor, Max Drawdown, Sharpe Ratio, Net PnL.
- **Strategy & Risk Configurator**: Fine-tune stop loss %, take profit targets, order size, and trailing stops.
- **Multi-Exchange Connector Ready**: Pre-architected interface for Binance, Coinbase, Kraken, and Bybit.
- **Executive Dark & Light Modes**: Bloomberg-terminal aesthetic with high-contrast trading telemetry.
- **Zero Heavy Backend Required**: Runs client-side for rapid evaluation or connects easily to custom trading microservices.

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Library**: React 19
- **Language**: TypeScript 5
- **Styling**: Tailwind CSS & Lucide React
- **Deploy**: Vercel / Cloudflare Pages / GitHub Pages

## 📦 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/euqirneh66/zenbot-pro.git
cd zenbot-pro
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
